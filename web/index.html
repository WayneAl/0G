Your agent hires an auditor. Every hop is signed.

Agent A pays Agent B over x402 to audit a token. B runs the inference inside a TEE and issues a seal. A verifies that seal — signature, live agent id, subject, request, expiry, attestation — and only then signs its own around it. The registry lists the token against seal A and enforces the LTV ceiling the seal carries.

See it work
npx @0x402/cli init
npx @0x402/cli underwrite 0xDB08Ce217Ce842b06baf76a0Bbb2C10f47fF9eB8

The second one runs without a key too: it stops at the auditor's quote and names the next step. init writes a burner key to ~/.acu/config.json and prints the faucet.

Now let your own agent do it
claude mcp add acu -- npx -y @0x402/mcp

No environment variables — it reads the key acu init wrote. Then say "underwrite 0xDB08…9eB8" in words, and your agent hires the auditor itself.
